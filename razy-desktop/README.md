# Razy для компьютера (с Discord-статусом)

## 1. Приложение в Discord
1. Откройте https://discord.com/developers/applications → **New Application**.
2. Назовите его **Razy** — именно это имя увидят друзья: «Слушает Razy».
3. Скопируйте **Application ID** и вставьте в `config.json` вместо `ВСТАВЬТЕ_APPLICATION_ID`.
4. Rich Presence → **Art Assets** → загрузите `assets/discord_logo_1024.png` под именем **razy_logo**.

## 2. Запуск
Нужен Node.js (nodejs.org). В папке проекта:
```
npm install
npm start        # запустить
npm run dist     # собрать установщик (.exe / .dmg / AppImage) в папке dist
```
Discord должен быть запущен на том же компьютере. Включите в Discord:
Настройки → Статус активности → «Делиться статусом активности».

## Поиск музыки в сети
Вкладка «Поиск в сети» ищет треки в каталоге Audius (музыку загружают сами артисты) и проигрывает их потоком. Нужен интернет.

## Установщик .exe для Windows
Двойной клик по `build-windows.bat` — соберёт `Razy-Setup-1.0.0.exe` в папке `dist`.
Без установки Node.js: загрузите проект на GitHub, вкладка Actions → Build Windows installer → Run workflow, затем скачайте Razy-Setup из результатов.

## Discord без пересборки
Application ID можно вставить прямо в приложении: кнопка «Discord» вверху справа (зелёная точка = подключено, красная = нет). Причина проблемы пишется там же.
Поиск в сети ищет только в Audius (полные треки, без превью).

## Подтверждение почты
Внизу окна — плашка «Не подтверждённый аккаунт». Нажмите её, введите почту, и на неё придёт 6-значный код.
Письма отправляются через mail.ru (smtp.mail.ru, порт 465). Данные ящика лежат в `mail-default.json` (файл в .gitignore, в репозиторий не попадает).
Пароль должен быть «паролем для внешних приложений»: mail.ru → Настройки → Пароли и безопасность → Пароли для внешних приложений. Обычный пароль от почты SMTP не примет.
Если файла нет, приложение один раз попросит ввести SMTP-данные и сохранит их на компьютере. После `npm install` (нужен nodemailer) всё готово.

## Discord у всех пользователей
Application ID зашивается в `config.json` при сборке — тогда статус работает у каждого, кто установил Razy (достаточно запущенного Discord и включённого «Делиться статусом активности»).
- `build-windows.bat` сам спросит ID, если он не указан.
- GitHub Actions: Settings → Secrets and variables → Actions → Variables → `DISCORD_CLIENT_ID`.
- Картинку `razy_logo` нужно загрузить в Rich Presence → Art Assets один раз.

## Jamendo
Бесплатные полные треки. Ключ (client_id) бесплатный: devportal.jamendo.com → создать приложение, вставить в Настройки → Поиск в сети.

## Импорт плейлиста Spotify по ссылке
Плейлисты → «Импортировать плейлист» → вставьте ссылку (в Spotify: Поделиться → Копировать ссылку) → «Импортировать». Файлы не нужны. Название плейлиста подставится само, а каждый трек подбирается по включённым источникам (Audius, Jamendo, превью), как и раньше.
- Плейлист должен быть **публичным** (личные и закрытые Spotify не отдаёт).
- Работает без ключей и входа: читается страница-плеер плейлиста (`open.spotify.com/embed/playlist/ID`). Spotify отдаёт через неё только **первые 50–100 треков**. Остальное можно добавить отдельным импортом списком текстом или CSV.
- Если Spotify изменит формат этой страницы, приложение скажет «Spotify не отдал список треков», а CSV и текст продолжат работать.

## Тексты песен из интернета (для любых треков, в том числе скачанных)
Кнопка текста в плеере сама ищет текст в сети (LRCLIB: с таймкодами и подсветкой строк; запасной источник lyrics.ovh: обычный текст). Для скачанных файлов запрос строится так: свой запрос из поля внизу окна → теги файла (ID3 у mp3, FLAC, M4A) → название из имени файла. Из имён вычищается мусор («01.», `[320kbps]`, `(Official Video)`, адреса сайтов), а если исполнитель неизвестен, разбирается «Исполнитель - Название» и «Название - Исполнитель». Если текст не нашёлся или не тот, поправьте строку «Исполнитель - Название» внизу окна и нажмите «Найти текст»: запрос запомнится для этого трека.

## Редактирование своих треков
У каждого загруженного с компьютера трека в списке есть кнопка с карандашом (а также рядом с громкостью и в полноэкранном плеере). Можно изменить название, исполнителя, альбом и обложку; кнопка «Поменять местами» исправляет случаи, когда Razy неверно разобрал имя файла. Правки хранятся в библиотеке Razy, сам файл не меняется.

## Discord: вводить ID не нужно
Приложение само использует Application ID из `config.json` (он вшивается в сборку). Окно «Discord» нужно только для диагностики: в нём написана причина, если статус не подключился, и есть кнопка «Переподключить». Свой ID из окна действует, пока вшитый ID не менялся; если вы пересобрали приложение с другим ID, старый сохранённый ID больше не перебивает новый.
Если Discord не принимает пометку «Слушает», приложение само отправит обычный статус «Играет в Razy».

## Профиль, «Стать артистом» и «Треки Razy»
В боковой панели появились две вкладки.
- **Профиль** — ваш аккаунт и кнопка «Стать артистом». В форме: имя артиста, жанр, о себе, фото и **данные подтверждения** (почта с кодом из письма, ссылка на профиль в другом сервисе, галочка «я автор музыки»). После создания в профиле видны статус подтверждения, кнопки «Выложить трек», «Редактировать», «Моя страница» и список ваших треков.
- **Треки Razy** — общий раздел: вкладка «Треки» (все выложенные треки, поиск) и «Артисты» (профили артистов, у каждого своя страница с песнями). Треки играют в обычном плеере Razy.

### Сервер (нужен, чтобы треки видели все)
**Встроенный сервер.** Приложение само запускает `server/server.js` при старте и останавливает при выходе, используя Node.js, который уже есть внутри Electron. Ставить Node.js пользователю не нужно. Работает, когда в `config.json` → `"server"` указан `localhost`. Данные лежат в папке профиля приложения (`%APPDATA%\Razy\server-data` в Windows). Важно: у каждого пользователя это его **собственный** сервер, и треки между людьми не делятся. Чтобы их видели все, разместите сервер на хосте и впишите его публичный адрес в `config.json` (тогда встроенный не запускается).

Отдельный запуск (для хостинга):
Аккаунты в приложении локальные, поэтому общие данные хранит маленький сервер без зависимостей (нужен только Node.js 18+):
```
npm run server                      # или: node server/server.js
RAZY_ADMIN=секрет npm run server    # с админ-функциями
```
Переменные: `PORT` (по умолчанию 3000), `DATA_DIR` (по умолчанию `server/data`, там база и аудио), `RAZY_ADMIN`.
Адрес сервера задаётся в `config.json` → `"server"` (вшивается в сборку; для GitHub Actions — переменная `RAZY_SERVER_URL`) или прямо в приложении: Профиль → Сервер Razy. Чтобы пользователи из интернета видели треки, разместите сервер на хосте с публичным адресом (лучше за HTTPS) и впишите этот адрес.

### Подтверждение артистов
- Если почта подтверждена кодом, профиль сразу получает статус «Подтверждён» и можно выкладывать треки.
- Если отправка писем на компьютере не настроена (см. «Подтверждение почты» выше), профиль уходит на проверку. Посмотреть заявки и одобрить:
```
curl -H "X-Admin: секрет" http://localhost:3000/api/admin/pending
curl -X POST -H "X-Admin: секрет" http://localhost:3000/api/admin/artists/ID/approve
curl -X POST -H "X-Admin: секрет" http://localhost:3000/api/admin/artists/ID/badge     # галочка у имени (повторный вызов снимает)
curl -X DELETE -H "X-Admin: секрет" http://localhost:3000/api/admin/artists/ID          # удалить артиста и его треки
curl -X DELETE -H "X-Admin: секрет" http://localhost:3000/api/tracks/ID                 # удалить один трек
```
Важно: код из письма проверяет само приложение, а не сервер, поэтому это защита от случайных ошибок, а не от злонамеренной подделки. Для строгой проверки используйте админ-одобрение и удаление.
Лимиты: аудио до 30 МБ (mp3, m4a, aac, ogg, wav, flac), до 100 треков на артиста.

## Оформление аккаунта
Профиль → «Настроить»: аватар (картинка), баннер (своя картинка или один из 8 цветов), кнопки «Убрать». Аватар показывается в профиле и в правом верхнем углу. Данные хранятся на этом устройстве отдельно для каждого аккаунта.

## Мини-плеер: «Карточка» и «Остров»
Кнопка с маленьким окошком вверху справа → **Вид**.
- **Карточка** — окно в углу экрана (как раньше).
- **Остров** — таблетка сверху по центру экрана. В покое показывает только название трека (и крошечный эквалайзер). Наведите курсор — она плавно раскрывается в полный плеер: обложка, название, исполнитель, визуализатор, время, перемотка, пауза и переключение треков. Курсор ушёл — остров снова сворачивается. Вокруг таблетки клики проходят сквозь окно, так что работе другим программам он не мешает.
- «Цвет острова»: **Чёрный** (как iPhone) или **По обложке** (градиент из цветов Razy).
Остров, как и карточка, появляется, когда вы ушли из Razy (свернули его или просто кликнули на другое окно) и играет музыка (или всегда, если выбрано «Всегда»). Вернулись в Razy — исчезает. «Показать сейчас» держит его на экране 10 секунд, чтобы успеть навести курсор.
Файлы: `app/island.html` (внешний вид), логика окна в `main.js` (блок «Мини-плеер»).
